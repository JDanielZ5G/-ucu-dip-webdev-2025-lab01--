### 🧠 Reflection Breakdown

#### 1. 🌐 What is an HTTP request/response?
- When you open your `index.html` in a browser, the browser sends an **HTTP request** to fetch the file.
- The server (or local environment like VS Code Live Server) replies with an **HTTP response**, which includes the requested file and a **status code** indicating success or failure.

#### 2. ✅ Which status code did you see, and what does it mean?
- The guide instructs you to inspect the **Network tab in Chrome DevTools**.
- You should see a **200 status code**, which means **“OK”**—the HTML file was successfully delivered without errors.
